## General info

The application monitors changes on the page for the given urls and according to the given css selector, and then informs about the changes with a sound.

## Built With

- Java - 21
- Kotlin
- Spring (Boot, Data JPA) - 3.3.4
- H2
- jUnit5

## Features

- Regular monitoring of changes on the website
- Notification with sound
